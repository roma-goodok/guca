# GUCA interface specification v1.0

## Назначение документа

Документ фиксирует структуру интерфейса, поведение элементов и приоритеты реализации нового демонстрационного сайта GUCA.

Для каждого элемента могут использоваться поля:

- **Элемент** — название блока, кнопки или настройки.
- **Состояние по умолчанию** — состояние при открытии страницы.
- **Наведение** — реакция на курсор на компьютере.
- **Клик / тап** — действие после нажатия мышью или пальцем.
- **Активное состояние** — визуальный признак выбранного режима или открытой панели.
- **Когда скрыт или недоступен** — условия показа элемента.
- **Tooltip** — короткая подсказка.
- **Приоритет** — P0, P1 или P2.

Символом `*` отмечены функции, которые описаны в спецификации, но не входят в первый рабочий вариант.

# Принятые решения

## 1. Поведение Step

- Step доступен всегда.
- На паузе клик выполняет 1 итерацию.
- Во время автоматического воспроизведения клик останавливает воспроизведение и выполняет ровно 1 итерацию.

## 2. Закрытие панелей

- **About** закрывается повторным кликом, кликом вне панели и клавишей Escape.
- **Выбор организма** закрывается повторным кликом, выбором организма и клавишей Escape. Клик вне списка его не закрывает.
- **Advanced** закрывается повторным кликом и клавишей Escape. Клик вне блока его не закрывает.
- **Genome overview** всегда открыт в P0.
- **Genome Editor** не закрывается по клику вне окна. Он закрывается крестиком, Cancel или клавишей Escape.
- Если в Genome Editor есть несохранённые значения полей, перед закрытием показывается предупреждение.

## 3. New genome

В P0 кнопка New genome загружает существующий `empty.yaml`:

- 1 узел A;
- 1 ген, превращающий A в B.

В будущем шаблон можно изменить на 1 узел A и 0 генов.

## 4. Звук

- В P0 звук выключен по умолчанию.
- Управление mute/unmute добавляется в P1.

## 5. Share

- Share располагается рядом с New genome, Upload и Download.
- Функция входит в P0, поскольку уже присутствует в текущей версии сайта.
- Share создаёт ссылку на текущую версию генома, включая применённые изменения.

## 6. Clone gene

- Clone сохраняется в Genome Editor.
- Функция входит в P0.

## 7. Несохранённые изменения

Геном получает статус `Unsaved changes` после:

- Add gene;
- Edit gene;
- Clone gene;
- Enable / Disable;
- Delete gene;
- изменения параметров генома в Advanced, которые входят в YAML.

Статус снимается после:

- Download;
- успешного Share, если ссылка содержит полную конфигурацию генома.

При выборе другого организма, New genome или возврате к начальному состоянию показывается предупреждение о потере изменений.

## 8. Genome и Genome Editor

- **Genome overview** — постоянно открытый блок на основном экране. Он показывает счётчик, плитки генов, enabled/disabled и гены, сработавшие на текущей итерации.
- **Genome Editor** — модальное окно поверх симуляции.
- Клик по плитке гена открывает режим **Edit gene**.
- Клик по Add gene открывает режим **New gene**.
- При открытии Genome Editor симуляция ставится на паузу.

## 9. Ошибки

- Ошибки Upload и сохранения показываются рядом с соответствующим элементом.
- Сообщение остаётся до закрытия, исправления или следующей попытки.
- В P0 обязательны `Invalid file` и ошибки неверных значений в Genome Editor.
- Информационные статусы добавляются в P1.

## 10. Форматы файлов

- Upload поддерживает `.yaml`, `.yml` и `.json`.
- Download сохраняет `.yaml`.

## 11. Display по умолчанию

- Значение по умолчанию: **Nodes & edges**.

## 12. Отделённые компоненты

По умолчанию для всех организмов:

- Keep only one component — OFF;
- Auto-dissolve detached subgraphs — OFF;
- отделённые части остаются и продолжают существовать.

## 13. Настройки при смене организма

- Параметры генома загружаются из его YAML.
- Глобальные параметры камеры, палитры и скорости не сбрасываются.
- Reset сохраняет текущие изменения генома и сбрасывает только состояние симуляции.
- Повторный выбор организма из каталога восстанавливает исходные параметры пресета.

# Приоритеты реализации

## P0 — первый рабочий вариант

| Блок | Элементы P0 | Критерий готовности |
|---|---|---|
| Общая структура | Новый layout, боковая панель, область симуляции, нижняя панель | Блоки помещаются без наложений |
| Верхняя панель | GUCA, About, GitHub | About открывается и закрывается, GitHub ведёт в репозиторий |
| Организмы | Категории, список организмов, Dumbbell по умолчанию | Выбор загружает геном, сбрасывает итерацию и ставит симуляцию на паузу |
| New genome | Кнопка New genome | Загружает `empty.yaml`, обновляет Genome overview, оставляет Genome Editor закрытым |
| Файлы | Upload YAML/YML/JSON, Download YAML, Share | Загрузка работает, ошибка понятна, экспорт содержит изменения, Share создаёт ссылку на текущий геном |
| Симуляция | Play/Pause, Step, Reset | Все сценарии работают по установленным правилам |
| Скорость | 0.5× / 1× / 2× | Текущая скорость видна |
| Информация | Iteration, nodes, edges | Значения обновляются после изменений |
| Вид | 2D / 3D | Переключение не сбрасывает геном |
| Инструменты | Move, Cut | Cut скрывается и отключается в 3D |
| Genome overview | Заголовок, количество генов, enabled/disabled, подсветка сработавших генов, Add gene | Состояние каждого гена понятно; блок всегда открыт |
| Genome Editor | Edit gene, New gene, Enable/Disable, Delete, Clone, Save/Add, Cancel | Форма открывается из плитки или Add gene; изменения отражаются в Genome overview |
| Advanced | Общий раскрывающийся блок и группы | Существующие настройки перенесены |
| Simulation settings | Maximum iterations, Maximum vertices, Iteration interval | Значения читаются из генома и меняются |
| Graph behavior | Keep one component, auto-dissolve, reseed, auto-center, auto-scale | Поведение соответствует переключателям |
| Appearance | Display, Fill faces, Face opacity, Gradient edges, Color palette, Reset colors | Настройки сразу меняют визуализацию |
| Machine settings | Nearest search depth, Topology semantics | Изменения входят в экспорт |
| Debug tools | Connect, Disconnect, Add, Remove, Change state, Connect nearest | Существующие операции сохранены |
| Ошибки | Invalid file, неверные значения Genome Editor | Пользователь понимает причину ошибки |
| Звук | OFF по умолчанию | Нет неконтролируемого звука |
| Адаптивность | Сохранить базовую работу на узком экране | Интерфейс не ломается на планшете |

# 3. Действия над геномом и файлами

Кнопки располагаются рядом с блоком Genome. Рекомендуемый порядок:

`New genome → Upload → Download → Share`

Иконка New genome должна отличаться от Add gene. Рекомендуется использовать иконку документа с плюсом, а обычный `+` оставить для Add gene.

| Поле | Описание |
|---|---|
| Элемент | New genome |
| Наведение | Подсветка фона |
| Клик / тап | Загружает `empty.yaml` |
| Подтверждение | Показывается при `Unsaved changes` |
| После действия | Симуляция ставится на паузу, итерация становится 0, Genome overview обновляется |
| Genome Editor | Остаётся закрытым |
| Tooltip | `Create an empty genome` |
| Приоритет | P0 |

## 3.2. Upload genome

|---|---|

| Название в P1 | `Custom: filename` |
| Ошибка | Сообщение рядом с Upload, остаётся до закрытия или новой попытки |

# 4. Genome overview

Genome overview находится на основном экране и всегда открыт в P0. Это не Genome Editor.

## 4.1. Заголовок и счётчик

| Поле | Описание |
|---|---|
| Элемент | `Genome` |
| Состояние по умолчанию | Показывает общее количество и количество включённых генов |
| Формат | `12 genes · 10 enabled` |
| Клик / тап по заголовку | Ничего не делает в P0 |
| Tooltip | `Genes define how nodes change and reproduce` |
| Сворачивание | P2 |

Количество генов, сработавших на текущей итерации, не выводится в счётчике. Оно показывается подсветкой плиток, чтобы число рядом с заголовком не менялось постоянно.

## 4.2. Плитки генов

| Состояние | Отображение |
|---|---|
| Enabled, не сработал на текущей итерации | Обычная плитка |
| Active на текущей итерации | Яркая рамка или заметная подсветка |
| Disabled | Приглушённая или перечёркнутая плитка |
| Открыт в Genome Editor | Отдельное выделение, визуально отличное от Active |

| Поле | Описание |
|---|---|
| Клик / тап | Открывает Genome Editor в режиме Edit gene |
| При открытии | Симуляция ставится на паузу |
| Tooltip | `View and edit gene rule` |

Термины:

- **Enabled** — ген включён и может сработать.
- **Active** — ген сработал на текущей итерации.

## 4.3. Add gene

| Поле | Описание |
|---|---|
| Элемент | Кнопка `+` после плиток генов |
| Клик / тап | Открывает Genome Editor в режиме New gene |
| При открытии | Симуляция ставится на паузу |
| Tooltip | `Add a new gene` |
| Приоритет | P0 |

# 5. Genome Editor

Genome Editor — общее название модального окна с формами Edit gene и New gene.

## 5.1. Общие правила

| Поле | Описание |
|---|---|
| Тип | Модальное окно поверх симуляции |
| Состояние по умолчанию | Закрыто |
| При открытии | Симуляция ставится на паузу |
| Клик вне окна | Ничего не делает |
| Крестик | Закрывает окно |
| Cancel | Закрывает окно без применения изменений формы |
| Escape | Закрывает окно |
| Несохранённые поля формы | Перед закрытием показывается предупреждение |
| Режимы | Edit gene / New gene |

## 5.2. Edit gene

| Поле | Описание |
|---|---|
| Открытие | Клик по существующей плитке гена |
| Содержимое | Условие, действие, состояния узлов и остальные поля правила |
| Enable / Disable | Включает или выключает ген |
| Clone | Создаёт копию гена и открывает её для редактирования |
| Delete | Удаляет ген после подтверждения |
| Save | Применяет изменения к гену и обновляет Genome overview |
| Cancel / крестик / Escape | Закрывает форму без применения новых значений |
| Клик вне | Ничего не делает |
| После Save | Геном получает статус `Unsaved changes` |

## 5.3. New gene

| Поле | Описание |
|---|---|
| Открытие | Клик по Add gene |
| Содержимое | Поля правила и `Insert at` для выбора позиции нового гена |
| Состояние формы | В каждом списке по умолчанию выбран первый допустимый элемент |
| Enable / Disable | Определяет начальное состояние нового гена |
| Add | Добавляет ген, обновляет Genome overview и закрывает форму |
| Cancel / крестик / Escape | Закрывает форму без создания гена |
| Клик вне | Ничего не делает |
| После Add | Геном получает статус `Unsaved changes` |

## 5.4. Unsaved changes*

| Поле | Описание |
|---|---|

# 11. Общие правила поведения

## 11.1. Одновременное открытие элементов

- About, список организмов и Advanced считаются раскрывающимися панелями.
- Открытие одной крупной панели может закрывать предыдущую, если они конфликтуют по расположению.
- Genome overview всегда остаётся открытым.
- Genome Editor открывается поверх страницы и не зависит от состояния Advanced.

## 11.2. Загрузка нового организма

После выбора организма:

- симуляция ставится на паузу;
- итерация становится 0;
- камера центрируется согласно Smooth auto-center;
- инструмент возвращается в Move;
- Genome overview обновляется;
- Genome Editor закрывается;
- параметры генома загружаются из YAML;
- глобальные настройки вида и скорости сохраняются;
- при `Unsaved changes` сначала показывается предупреждение.

## 11.3. Reset

Reset:

- возвращает граф к начальному состоянию текущего генома;
- ставит симуляцию на паузу;
- сбрасывает итерацию до 0;
- сохраняет применённые изменения генов и настроек генома.

## 11.4. Мобильный и планшетный интерфейс*

Проверить:

- все действия работают по тапу;
- важная информация не зависит от hover;
- области нажатия достаточно крупные;
- панели не выходят за границы экрана;
- tooltip не является единственным источником информации.

## 11.5. Клавиатура*

Возможные сочетания:

- Space — Play / Pause;
- R — Reset;
- S — Step;
- Escape — закрыть верхнюю открытую панель или Genome Editor;
- 2 / 3 — переключить 2D / 3D.

Приоритет — P2, кроме базовой поддержки Escape в P1 accessibility.
